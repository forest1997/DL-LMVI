# D-FFOCT Denoising

This folder contains MATLAB code for training and running the D-FFOCT denoising model used in the DL-LMVI study.

The model converts quantitative maps from a short 48-frame acquisition into denoised maps corresponding to a longer 512-frame acquisition. It predicts:

- `H_Hz`: dynamic center frequency
- `V_power`: dynamic intensity

## Requirements

- MATLAB R2025b
- Deep Learning Toolbox
- Image Processing Toolbox
- Parallel Computing Toolbox and a CUDA-compatible GPU are optional

## Folder structure

- `source/`: preprocessing, training and inference code
- `model/`: trained model checkpoint
- `config/`: training, validation and test split files
- `data/`: one example input and matched reference
- `output/`: example denoised results
- `tests/`: package verification script
- `provenance/`: training history and release information

## Run the example

Open MATLAB, change the current folder to `source/`, and run:

```matlab
run_DFFOCT_denoising
```

To run inference on the CPU:

```matlab
run_DFFOCT_denoising(false)
```

Results are saved in:

- `output/denoised/quantitative_maps/`
- `output/denoised/rgb_preview/`

## Train the model

The complete paired training dataset is required. After placing the quantitative maps in the corresponding data folders, run:

```matlab
train_DFFOCT_48HVto512HV_quant_customLoop
train_DFFOCT_logV_intensityPreserving_finetune
```

The included example alone is intended for inference and package verification, not full training.

## Input format

Input MAT files should contain quantitative D-FFOCT maps generated by:

```matlab
generate_DFFOCT_quantMaps_fromRaw
```

The supplied example uses data acquired at 100 Hz with 48 frames. See the configuration sections in the MATLAB scripts when using another acquisition format.

## Verify the package

Run the following command from the `tests/` folder:

```matlab
verify_packaged_example
```
