# LD Tracking and Plots

Lipid droplet trajectory data and MATLAB code for reproducing Fig. 4o.

## Files

- `Fig4o_from_trajectories_Experiments.m`: analyzes deposited 2D centroid trajectories and reproduces the plot.
- `Fig4o_Reproducibility_Experiments.xlsx`: trajectory coordinates and reproducibility data.

## Usage

Keep both files in the same folder. Open the MATLAB script and run it.

The script uses a pixel size of 0.2 micrometers and a frame interval of 0.48 seconds. See the script for the MSD-based inclusion rule and analysis details.

The original script and workbook are uploaded unchanged. MATLAB execution was not tested during this upload.
